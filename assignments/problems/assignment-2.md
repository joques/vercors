# Problem

All models should be built using the **Julia** Programming language.

## Problem 1 

The "file dia.csv" contains drug-induced autoimmune data. The features are described in the accompanying "RDKit_ChemDes.xlsx" file. Your task is to cluster these data points using the following algorithms:

1. K-Means;
1. Agglomerative Clustering;
1. Gaussian Mixture.

Which algorithm yields the best clusters? Why?

## Problem 2 

The file "ag_soybean.arff" contains a dataset on soybean diseases. Your task is to build a classifier using the following ensemble methods:

1. Boosting;
1. Bagging;
1. Stacking.

You will also compare each of these classifiers to a decision tree classifier. For each model, you will provide the following metrics:

- accuracy;
- precision;
- recall;
- sensitivity.

You will also plot the receiver-operating characteristic curve (ROC) and discuss the area under the curve (AOC) for each model.
