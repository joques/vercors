# Problems

All models should be built using the **Julia** Programming language.

## Problem 1 

The dataset in this Github [repository](https://github.com/sebischair/Medical-Abstracts-TC-Corpus) contains a corpus of medical summaries of patient conditions. Your task is to build a deep neural network classifier using a long short-term memory (LSTM) architecture.

You will provide the following metrics for your model:

- accuracy;
- precision;
- recall;
- sensitivity.

You will also plot the receiver-operating characteristic curve (ROC) and discuss the area under the curve (AOC) for each model.

## Problem 2 

The catalogue at this [link](https://www.kaggle.com/datasets/muratkokludataset/rice-image-dataset) contains images of five types of rice: **Arborio**, **Basmati**, **Ipsala**, **Jasmine** and **Karacadag**. Your task is to build a classifier using a convolutional neural network (CNN). You will follow the AlexNet architecture described [here](https://proceedings.neurips.cc/paper_files/paper/2012/file/c399862d3b9d6b76c8436e924a68c45b-Paper.pdf).

You will provide the following metrics for your model:

- accuracy;
- precision;
- recall;
- sensitivity.

You will also plot the receiver-operating characteristic curve (ROC) and discuss the area under the curve (AOC) for each model.
