# Problem

All models should be built using the **Julia** Programming language.

## Problem 1 

Consider the **Global Food Wastage** dataset which is available [here](https://www.kaggle.com/datasets/atharvasoundankar/global-food-wastage-dataset-2018-2024). You are tasked with building **regression models** to predict the following:

* economic loss due to fruit wastage 
* household waste in dairy product

## Problem 2 

This [dataset](https://www.kaggle.com/datasets/andrewmvd/fetal-health-classification) contains fetal health information to help prevent child and maternal mortality. Your task is to build a classifier to predict a fetus's health.

## Assessment Criteria

We will follow the criteria below to assess the problem:

- Exploratory data analysis. (30%)
- Model implementation. (45%)
- Evaluation metrics and model tuning. (20%)
- Overall quality of solution in **Julia**. (5%)
